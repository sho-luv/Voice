**C. Create dmg-background.png** (per D-22: custom DMG background image with Voice logo and drag-to-Applications arrow visual).

Generate the background image programmatically using a Swift script. Create and run a temporary Swift file that uses CoreGraphics to render a 660x400 PNG with:
- Light gradient background (white to light gray, matching macOS DMG aesthetic)
- The Voice app icon rendered at the left position (180, 195) — extract from Voice.app/Contents/Resources/AppIcon.icns using NSImage, or draw a placeholder microphone icon
- A right-pointing arrow in the center (drawn with CoreGraphics paths, subtle gray color)
- The Applications folder icon at the right position (480, 195) — use NSWorkspace to get the folder icon, or draw a generic folder shape
- No text labels (the icon positions match the create-dmg --icon and --app-drop-link coordinates)

The Swift script approach:
```bash
cat > /tmp/generate-dmg-bg.swift << 'SWIFT'
import Cocoa

let width = 660
let height = 400
let colorSpace = CGColorSpaceCreateDeviceRGB()
let context = CGContext(data: nil, width: width, height: height, bitsPerComponent: 8,
                        bytesPerRow: 4 * width, space: colorSpace,
                        bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)!

// Light gradient background
let gradient = CGGradient(colorsSpace: colorSpace,
    colors: [CGColor(red: 0.96, green: 0.96, blue: 0.97, alpha: 1.0),
             CGColor(red: 0.90, green: 0.90, blue: 0.92, alpha: 1.0)] as CFArray,
    locations: [0.0, 1.0])!
context.drawLinearGradient(gradient, start: CGPoint(x: 0, y: CGFloat(height)),
                           end: CGPoint(x: 0, y: 0), options: [])

// Draw a subtle right-pointing arrow between icon positions (center area)
let arrowX: CGFloat = 310  // Between 180 and 480
let arrowY: CGFloat = 205  // Vertically centered
context.setStrokeColor(CGColor(red: 0.65, green: 0.65, blue: 0.68, alpha: 1.0))
context.setLineWidth(3.0)
context.setLineCap(.round)
context.setLineJoin(.round)
// Arrow shaft
context.move(to: CGPoint(x: arrowX - 20, y: arrowY))
context.addLine(to: CGPoint(x: arrowX + 20, y: arrowY))
// Arrow head
context.move(to: CGPoint(x: arrowX + 10, y: arrowY - 12))
context.addLine(to: CGPoint(x: arrowX + 20, y: arrowY))
context.addLine(to: CGPoint(x: arrowX + 10, y: arrowY + 12))
context.strokePath()

// Save as PNG
let image = context.makeImage()!
let url = URL(fileURLWithPath: "dmg-background.png")
let dest = CGImageDestinationCreateWithURL(url as CFURL, "public.png" as CFString, 1, nil)!
CGImageDestinationAddImage(dest, image, nil)
CGImageDestinationFinalize(dest)
print("Created dmg-background.png (\(width)x\(height))")
SWIFT
swiftc -framework Cocoa -framework CoreGraphics -framework ImageIO /tmp/generate-dmg-bg.swift -o /tmp/generate-dmg-bg
cd "$SCRIPT_DIR" && /tmp/generate-dmg-bg
rm -f /tmp/generate-dmg-bg.swift /tmp/generate-dmg-bg
```

Run this from the repo root directory so `dmg-background.png` is created at the project root (same directory as create-dmg.sh). The image is intentionally minimal — a subtle gradient with an arrow indicator. The actual Voice.app icon and Applications folder icon are rendered by the Finder when the DMG is mounted; the background just provides the visual context. Exact design is Claude's discretion per CONTEXT.md.

If the Swift script approach fails for any reason, fall back to using `sips` to create a solid-color 660x400 PNG:
```bash
# Fallback: create a plain light-gray background
python3 -c "
import struct, zlib
width, height = 660, 400
# Light gray RGB
row = b'\x00' + b'\xf0\xf0\xf2' * width
raw = row * height
def png_chunk(ctype, data):
    c = ctype + data
    return struct.pack('>I', len(data)) + c + struct.pack('>I', zlib.crc32(c) & 0xffffffff)
with open('dmg-background.png', 'wb') as f:
    f.write(b'\x89PNG\r\n\x1a\n')
    f.write(png_chunk(b'IHDR', struct.pack('>IIBBBBB', width, height, 8, 2, 0, 0, 0)))
    f.write(png_chunk(b'IDAT', zlib.compress(raw)))
    f.write(png_chunk(b'IEND', b''))
print('Created fallback dmg-background.png')
"
```
